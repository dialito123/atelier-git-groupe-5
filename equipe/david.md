## Quiz

1. **Après un `git commit`, où se trouve le commit ?**
   Uniquement dans mon dépôt local (l'historique Git de mon Codespace). Il n'est pas encore sur GitHub.

2. **Après un `git push`, où se trouve-t-il ?**
   Aussi sur le dépôt distant GitHub (`origin`). Les autres membres peuvent le récupérer avec `git pull`.

3. **Que se passe-t-il si on supprime un Codespace après un commit sans push ?**
   Le commit est perdu définitivement, car il n'existait que localement dans le Codespace.
